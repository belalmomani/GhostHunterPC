# الخصوصية

## جمع معلومات الجهاز

تقرأ لوحة المعلومات بيانات النظام والأقراص محليًا للعرض فقط.

## محقق الملفات

- لا يبدأ فحص الملفات تلقائيًا ولا يفحص القرص بالكامل؛ يختار المستخدم المجلد صراحةً.
- قراءة بيانات الملفات والتعرف على تواقيعها الرقمية وحساب SHA-256 تتم محليًا. التحقق من التوقيع يستخدم ذاكرة Windows المؤقتة لمنع جلب معلومات عبر الإنترنت.
- لا تُرفع الملفات أو محتوياتها، ولا تُحذف أو تُعزل.
- يعرض التطبيق مؤشرات وصفية فقط، وليس محركًا موثوقًا لاكتشاف البرمجيات الخبيثة. الملف المجهول أو غير الموقّع لا يُعد بحد ذاته دليلًا على الضرر.
- أخطاء الوصول إلى الملفات تُعرض للمستخدم، مع مواصلة فحص بقية الملفات الممكن الوصول إليها.

## الملفات المكررة والقديمة

- يبدأ التحليل فقط بعد اختيار المستخدم مجلدًا؛ تُستبعد مجلدات Windows والبرامج المثبتة افتراضيًا ولا تُتبع الروابط الرمزية.
- تُجمع الملفات بحسب الحجم أولًا، ثم تُحسب بصمات SHA-256 محليًا للمرشحين متساويي الحجم فقط. لا يعتمد التطابق على الاسم.
- قائمة الملفات القديمة تعتمد تاريخ التعديل المسجل، ولا تدّعي أن ذلك يثبت آخر استخدام للملف.
- لا يُحذف شيء تلقائيًا. يتطلب نقل العناصر المحددة إلى سلة المحذوفات موافقة صريحة، ويُعاد التحقق من بصمة الملف قبل النقل.

## بصمة الجهاز والخط الزمني

- تُجمع اللقطة فقط عند طلب إنشاء خط أساس أو المقارنة: معلومات النظام المتاحة، أسماء البرامج المثبتة، أسماء العمليات وPID وقت الجمع، وعناصر Run/RunOnce المتاحة في السجل. قد يحتوي سجل بدء التشغيل على مسارات تنفيذ.
- يُحفظ خط الأساس والأحداث محليًا في `%LOCALAPPDATA%\GhostHunterPC\pc-history.json`. لا تُحفظ محتويات الملفات الشخصية ولا تُرفع البيانات تلقائيًا.
- يسجل الخط الزمني أحداث تشغيل التطبيق وإنشاء خط أساس والمقارنة. استيراد آخر 24 ساعة من سجل Windows System يدوي واختياري، ويعمل بصلاحيات المستخدم الحالية؛ قد يتعذر حسب الأذونات أو إعدادات النظام.
- لا توجد أحداث سابقة على بدء الجمع. تغير اللقطة وصف للمقارنة وليس دليلًا على اختراق. عند وجود نقص في القراءة، تتجنب المقارنة استنتاج إزالة العناصر من الفئات غير المكتملة.
- يمكن للمستخدم تصدير البيانات المجمعة إلى JSON من خلال مسار يختاره. يتضمن التصدير معلومات قد تكشف أسماء برامج أو عمليات أو مسارات بدء التشغيل، لذلك ينبغي حفظه ومشاركته بحذر.

## نفّذها لأجلي

- تعرض المهام الخمس خطة محلية توضح النطاق والبيانات أو الملفات المتأثرة قبل التأكيد.
- لا تُنشئ أوامر PowerShell/CMD ولا تشغّل نصًا مولدًا؛ تستخدم فقط مسارات الأدوات المسموح بها والموجودة.
- تأكيد الخطة يفتح الأداة الفعلية للمهام التي تحتاج تحديد مجلد أو مراجعة. لا يبدأ نقل الملفات أو نقلها إلى سلة المحذوفات من هذه الصفحة؛ للأدوات الأصلية تأكيداتها وإلغاءاتها الخاصة.
- جمع معلومات حالة الجهاز يستخدم خدمة القراءة المحلية القائمة. مراجعة برامج بدء التشغيل تستخدم لقطة PC DNA التي تشمل أيضًا معلومات النظام والبرامج والعمليات، وتحفظ محليًا.
- مهمة البحث المخصص عن الملفات الكبيرة معلنة كغير متاحة؛ لا يحاكي التطبيق نتائجها.
- يسجل التطبيق معرف المهمة ونتيجتها أو إلغاءها محليًا في ملف PC Timeline. لا يسجل مسارات الملفات أو محتواها ولا يرفع البيانات.

## التقارير والإعدادات

- تُحفظ الإعدادات في `%LOCALAPPDATA%\GhostHunterPC\settings.json` وسجل PC Timeline في `%LOCALAPPDATA%\GhostHunterPC\pc-history.json`.
- يمكن للمستخدم إيقاف حفظ أحداث التطبيق الجديدة؛ لا يحذف ذلك السجل السابق أو خط أساس الجهاز.
- مجلدات الاستثناء يحددها المستخدم وتُستبعد من فحوص محقق الملفات والتكرارات ومعاينة تنظيم الملفات.
- التقارير CSV/JSON لا تحتوي مسارات الملفات أو أسماء العمليات؛ تقرير التغييرات يقدم أعدادًا مجمعة حسب الفئة والحالة. يختار المستخدم مجلد الحفظ، ولا تُرفع التقارير.
- لا تتوفر ميزة PDF أو الإشعارات في هذه النسخة، ولا تدّعي الواجهة تشغيلها.

## متطلبات الوظائف المستقبلية

- تحديد البيانات التي تحتاجها الوظيفة والغرض منها قبل تنفيذها.
- تقليل البيانات المجمعة إلى الحد الأدنى، وشرحها للمستخدم بوضوح.
- عدم إرسال بيانات خارج الجهاز دون موافقة صريحة ووثائق توضح الوجهة والغرض.
- وضع سياسة احتفاظ وحذف للسجلات والإعدادات قبل إضافة التخزين.
- تجنب تسجيل المسارات أو المحتوى أو المعرّفات الشخصية ما لم تكن ضرورية ومعلنة.
