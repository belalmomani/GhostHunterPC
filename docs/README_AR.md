# Ghost Hunter PC

## نبذة

مشروع تطبيق سطح مكتب لنظام Windows مبني باستخدام WPF و.NET. هذه النسخة تؤسس الهيكل فقط؛ ولا تنفّذ فحصًا أو تنظيفًا أو تغييرات على النظام.

## المتطلبات

- Windows.
- .NET SDK 10.0 أو أحدث من خط .NET 10.
- Visual Studio 2022 أو محرر يدعم مشاريع WPF، مع مكوّن تطوير سطح المكتب .NET عند استخدام Visual Studio.

## البناء والتشغيل

من جذر المشروع:

```powershell
dotnet build .\GhostHunterPC.sln
dotnet run --project .\src\GhostHunterPC\GhostHunterPC.csproj
```

يلزم توفر SDK وحزمة استهداف Windows المناسبة. لم يتم تأكيد توفرهما أو تنفيذ البناء في جلسة التأسيس.

## هيكل المجلدات

- `src/GhostHunterPC`: تطبيق WPF.
- `docs`: وثائق المشروع والأمان والخصوصية والتقدم.
- `tests`: سيُضاف عند بدء كتابة اختبارات للمكونات.
- `assets`: سيُضاف عند الحاجة إلى موارد مرئية.
- `scripts`: سيُضاف عند الحاجة إلى سكربتات موثقة وآمنة.
