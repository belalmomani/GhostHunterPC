# تقرير البناء والاختبار والمراجعة التقنية

## النطاق والبيئة

- تمت مراجعة الحل ومشروعي التطبيق واختبار الدخان، ومواضع WPF/XAML، والتوطين والإعدادات والتقارير، وخدمات الملفات والسجل، وViewModels للعمليات غير المتزامنة والتأكيد والإلغاء.
- يستهدف التطبيق `net10.0-windows` ويستخدم WPF. SDK المستخدم: `10.0.113`.
- مشروع `GhostHunterPC.SmokeTests` تطبيق تنفيذي مستقل، ولا يعرّف إطار اختبار أو حزمة اكتشاف اختبارات في ملف المشروع.
- التحقق هنا هو بناء الحل ومراجعة ساكنة وتشغيل اختبارات الدخان؛ لم تُجرَ جلسة UI Automation أو اختبار تفاعلي لنافذة WPF في هذا الجزء.

## الأوامر والنتائج

| الأمر | النتيجة الفعلية |
|---|---|
| `dotnet restore .\GhostHunterPC.sln` | اكتمل بنجاح؛ كل المشاريع محدّثة ولا تحتاج استعادة إضافية. |
| `dotnet build .\GhostHunterPC.sln --no-restore --verbosity minimal` | اكتمل بنجاح: صفر تحذيرات وصفر أخطاء، وبُني التطبيق ومشروع اختبار الدخان. شمل بناء WPF ترجمة XAML. |
| `dotnet test --solution .\GhostHunterPC.sln --no-restore --verbosity minimal` | فشل هذا الاستدعاء بسبب صيغة `--solution` غير المقبولة في هذا الحل/المشغل (`MSB1001: Unknown switch`)، وليس بسبب فشل اختبار. |
| `dotnet test .\GhostHunterPC.sln --no-restore --verbosity minimal` | انتهى برمز خروج 0، لكن لم يطبع اكتشافًا أو نتائج اختبارات. لا توجد حزمة إطار/محول اختبارات في مشروع الاختبار؛ لذلك لا يُسجل هذا كنجاح لاختبارات `dotnet test`. |
| `dotnet run --no-build --no-restore --project .\tests\GhostHunterPC.SmokeTests\GhostHunterPC.SmokeTests.csproj` | اكتمل بنجاح: 372 تحققًا ناجحًا. شملت الرسائل التحقق من الإجراءات المسموح بها والتأكيد، معلومات الجهاز والتوطين، التنظيم والتعارضات والتراجع، التكرارات، المراقبة، وسجل PC DNA/Timeline. قرأ الاختبار قرصين حقيقيين، دون أخطاء أقسام جزئية. |

## المراجعة والنتائج

- **البناء وXAML:** لم يظهر خطأ بناء أو ترجمة XAML أو تحذير. لا يكفي ذلك وحده لإثبات صحة كل ربط وقت التشغيل؛ لم يُجرَ اختبار تفاعلي للواجهة في هذا الجزء.
- **الاستثناءات:** عولجت حالات الملفات/الوصول المتوقعة في المسارات التي تمت مراجعتها بعرض أخطاء أو نتائج جزئية؛ لم يظهر استخدام لالتقاط عام صامت في البحث الساكن المنفذ.
- **سلامة الملفات:** معاينة المنظم تسبق النقل، وتوجد موافقة صريحة؛ معالجة التعارض قد تحفظ نسخة احتياطية، والتراجع يتحقق من SHA-256. نقل التكرارات إلى سلة المحذوفات يتطلب تأكيدًا ويعيد فحص بصمة المحتوى قبل النقل. لا يوجد حذف مباشر لملفات النظام في المسارات التي تمت مراجعتها، ولا تتبع لهذه الميزات آلية تعطيل Defender أو جدار الحماية.
- **التزامن والإلغاء:** عمليات الفحص/النقل الثقيلة المنفذة في ViewModels تعمل خارج واجهة المستخدم، وتُحدّث النتائج بعد العودة إلى سياق الواجهة؛ تتوفر رموز إلغاء للعمليات الطويلة، وقفل يمنع تداخل تحديثات مراقبة الجهاز.
- **الصلاحيات وتشغيل العمليات:** تعمل قراءات النظام بصلاحيات المستخدم الحالي. استيراد سجل Windows يستعمل `wevtutil.exe` بمعاملات منفصلة عبر `ArgumentList` مع مهلة؛ لا تُنفذ أوامر حرة مولدة.
- **الإجراءات الخطرة:** اختبار الدخان يؤكد رفض الخطة غير المعروفة أو المعدلة أو غير المتاحة ورفض التنفيذ دون تأكيد. واجهات نقل/استبدال الملفات وسلة المحذوفات تطلب تأكيدًا.
- **البيانات والخصوصية:** بيانات السجل والإعدادات محلية، والتصدير لمسار يختاره المستخدم؛ لم يظهر مسار إرسال بيانات عبر الشبكة ضمن الخدمات التي تمت مراجعتها. بعض سجلات الجهاز قد تتضمن أسماء برامج/عمليات ومسارات بدء التشغيل، وهو موضح في وثائق الميزة.
- **التوطين والإعدادات:** اختبار الدخان تحقق من موارد اللغتين والثقافتين، وحفظ الإعدادات واستعادتها. ملفات الموارد موجودة ضمن المشروع ويُنسخ ملفا JSON إلى مخرجات التطبيق.
- **المراجع:** أظهر جرد المشاريع ملفات التطبيق واختبار الدخان المتوقعة؛ نجح البناء دون مراجع أو ملفات XAML مفقودة.
- **الأخطاء المكتشفة والمصلحة في هذا الجزء:** لم يُعثر على خطأ في التطبيق يمكن إعادة إنتاجه لإصلاحه. محاولة `dotnet test` الأولى استخدمت خيارًا غير مقبول، ثم جُرّب الاستدعاء المتوافق؛ لا تمثل مشكلة في مصدر التطبيق ولا تُحسب نتيجة اختبار.

## المشكلات المتبقية والميزات غير المكتملة

- لا يوجد إطار اختبار آلي قابل للاكتشاف بواسطة `dotnet test` حاليًا؛ التحقق المتاح هو تطبيق اختبار الدخان الذي يشغّل تحققاته عند تشغيله مباشرة.
- لم يُنفذ اختبار تفاعلي لواجهة WPF أو اختبار تثبيت/تغليف في هذا الجزء.
- ميزات صرّحت وثائق المنتج بعدم توفرها: العثور المخصص على الملفات الكبيرة، تصدير PDF، والإشعارات. كما أن الفحص الشامل للنظام غير منفذ. لا يدعي التطبيق تنفيذ هذه الميزات.
- لم تظهر إصلاحات أو مراجع مفقودة أثناء المراجعة الحالية. لا يتضمن هذا التقرير تدقيقًا أمنيًا متخصصًا أو ضمانًا شاملًا لكل مسارات التشغيل.

لم تُنفذ عملية تغليف.
