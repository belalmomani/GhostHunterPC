# حالة الميزات

| الميزة | الحالة | ملاحظات |
|---|---|---|
| حل ومشروع WPF أساسيان | أُنشئ وتحقق بناؤه | يستهدف `net10.0-windows`؛ البناء اكتمل دون تحذيرات أو أخطاء. |
| نافذة WPF رئيسية | منفذة ومختبرة تفاعليًا | ظهرت نافذة التطبيق وبقيت مستجيبة أثناء اختبار UI Automation. |
| التنقل بين أقسام التطبيق | منفذ ومختبر تفاعليًا | نجحت الصفحات العشر في التنقل وتحديث عنوان الصفحة. |
| لوحة التحكم ومعلومات النظام | منفذة ومختبرة على الجهاز الحالي | Windows والمعالج والذاكرة والأقراص ومدة التشغيل؛ النوى الفيزيائية غير متاحة في هذا الجهاز. |
| تحديث معلومات الجهاز | منفذ ومختبر تفاعليًا | التحديث التلقائي والزر اليدوي؛ عُرضت بيانات الأقراص C: وD:. |
| تبديل اللغة والمظهر | منفذ ومختبر تفاعليًا | العربية/الإنجليزية والداكن/الفاتح؛ أُصلح تحديث تسمية زر المظهر بعد تغيير اللغة. |
| محقق الملفات | منفذ | فحص مجلد يختاره المستخدم يدويًا، مع بيانات الملف ونوع محتواه المعروف والتوقيع والناشر والتحذيرات الوصفية. |
| الملفات المكررة والقديمة | منفذة ومختبرة | اختيار مجلد، تجميع مرشحي التكرار حسب الحجم ثم SHA-256 للمحتوى، وعرض الملفات الأقدم من مدة يحددها المستخدم (افتراضيًا 6 أشهر). |
| تقدير المساحة وإدارة التكرارات | منفذ | شرح حساب المساحة مع إبقاء نسخة، اختيار يدوي لا يشمل النسخة الموصى بإبقائها، ونقل المحدد إلى سلة المحذوفات بعد التأكيد والتحقق مجددًا من SHA-256. |
| استبعاد النظام والبحث والفرز | منفذ | رفض مجلدات Windows/البرامج المثبتة، توضيح أن تاريخ التعديل لا يثبت الاستخدام، مع حالات فارغة وأخطاء وبحث وفرز. |
| منظم الملفات الذكي | منفذ ومختبر | يراجع خطة تصنيف ونقل الملفات إلى وجهة يحددها المستخدم، مع خيار التجميع حسب شهر التعديل. |
| معاينة وتعارضات المنظم | منفذة ومختبرة | تظهر الملفات والحجم الإجمالي والتعارضات قبل التنفيذ؛ النقل لا يبدأ إلا بعد تأكيد صريح. |
| معالجة التعارضات وسجل المنظم | منفذة ومختبرة | تخطي أو إعادة تسمية أو استبدال بموافقة مع حفظ نسخة؛ سجل للنجاح والتخطي والفشل والتراجع. |
| التراجع عن نقل المنظم | منفذ ومختبر | يتحقق من SHA-256 للملف المنقول والنسخة الاحتياطية قبل الاسترجاع، ويرفض التراجع إن تغيرت الملفات. |
| حماية مجلدات النظام والتصنيف | منفذة ومختبرة | استبعاد مجلدات Windows والبرامج المثبتة؛ تواقيع المحتوى تسبق الامتداد، والنصوص تتحقق من محتواها. |
| SHA-256 للملف المحدد | منفذ ومختبر ببصمات معروفة | لا تُحسب البصمة إلا بطلب المستخدم؛ اجتاز الاختبار لمحتوى `abc` والملف الفارغ. |
| الخصوصية وسلامة محقق الملفات | منفذة | لا مسح تلقائي للقرص ولا رفع أو حذف أو عزل؛ يستخدم التحقق من التوقيع ذاكرة Windows المؤقتة فقط. |
| البحث والفرز وإيقاف الفحص | منفذة | بحث في البيانات ومؤشرات التوقيع، وفرز أعمدة النتائج، وتقدم وحالات خطأ وإلغاء. |
| عزل أخطاء الوصول للملفات | ناجح بالاختبار | أثبت اختبار الملف المقفول استمرار عرض الملف القابل للقراءة بدل إيقاف الفحص. |
| وقت آخر قراءة معلومات | منفذ ومختبر تفاعليًا | يعرض وقت آخر قراءة ناجحة خلال جلسة التطبيق؛ لا يدّعي أنه فحص شامل. |
| فحص شامل أجراه البرنامج | لم يبدأ | تعرض اللوحة «لم يُنفّذ بعد» صراحةً. |
| فحص النظام | لم يبدأ | يتطلب متطلبات محددة ونموذج صلاحيات وموافقة المستخدم. |
| تنظيف الملفات أو التغييرات | لم يبدأ | لا حذف أو تنظيف تلقائي في هذه المرحلة. |
| حفظ الإعدادات | لم يبدأ | تحدد سياسة التخزين والخصوصية قبل التنفيذ. |
| اختبار دخان لخدمة معلومات الجهاز والتوطين | ناجح | نجحت 9 تحققّات؛ قُرئ قرصا C: وD: الحقيقيان. |
| التعامل مع قرص غير متاح أو استثناء قراءة | ناجح بالاختبار المحاكى | اختُبر قرص غير جاهز واستثناء قراءة وسعة غير متسقة عبر مصدر مزيف؛ لم يُعدّل أي قرص حقيقي. |
| اختبارات محقق الملفات | ناجحة | تحقق 13 اختبار دخان من ضمنها بصمات SHA-256 معروفة، كشف اختلاف الامتداد، تحذيرات غير جازمة، وتعامل مع ملف مقفول. |
| اختبارات منظم الملفات | ناجحة | إجمالي 23 تحققًا في اختبار الدخان؛ تشمل تصنيف الفئات المطلوبة والمعاينة والتعارض والتخطي وإعادة التسمية والاستبدال والتراجع الآمن والتجميع الشهري ورفض مجلد Windows. |
| اختبارات الملفات المكررة والقديمة | ناجحة | ضمن 27 تحققًا إجمالًا؛ اختُبر SHA-256 لنسختين متطابقتين، واختلاف محتوى ملفات متساوية الحجم والاسم، وتاريخ 6 أشهر، المجلد الفارغ، رفض مجلد Windows، ورفض نقل ملف تغيّرت بصمته. |
| مراقبة موارد الجهاز والعمليات | منفذة ومختبرة | تعرض CPU وRAM والأقراص الثابتة والعمليات وPID واستخدام الذاكرة؛ التحديث اليدوي أو الدوري قابل للإيقاف وضبط الفاصل، والقراءة تتم خارج واجهة المستخدم بصلاحيات المستخدم الحالية. |
| البحث والفرز ومعالجة أخطاء مراقبة النظام | منفذة ومختبرة | البحث باسم العملية وPID، وفرز قوائم الأقراص والعمليات، مع إظهار بيانات العمليات التي يتعذر الوصول إليها وأخطاء القراءة دون إسقاط بقية النتائج. لا يوجد خيار لإنهاء العمليات. |
| اختبارات مراقبة النظام | ناجحة | اجتازت اختبارات المصدر المحاكى رفض الوصول وانتهاء عملية أثناء القراءة، وتغير قائمة العمليات بين التحديثات، وحساب CPU من فرق عينتين. |
| رسائل Output/Debug | غير متاحة في هذه الجلسة | لم يكن مصحح أخطاء متصلًا؛ فُحص سجل أحداث Windows ولم تظهر أخطاء للتطبيق. |
| PC DNA وخط أساس الجهاز | منفذ ومختبر | يجمع عند طلب المستخدم معلومات النظام والبرامج والعمليات وعناصر بدء التشغيل المتاحة، ويحفظ وقت كل عنصر، ويقارن الإضافات والإزالة والتغييرات مع تجنب استنتاج إزالة العناصر من الفئات التي تعذر قراءتها. |
| PC Timeline | منفذ | سجل محلي لأحداث البرنامج منذ بدء الجمع، مع استيراد يدوي اختياري لآخر 24 ساعة من سجل Windows System عند توفر الصلاحيات. يميز المصدر ويتيح تصفية التاريخ والنوع وعرض التفاصيل. |
| خصوصية وتصدير PC DNA/Timeline | منفذة ومختبرة | تخزين JSON محلي تحت LocalAppData وتصدير يختاره المستخدم. لا تحفظ محتويات الملفات ولا ترفع البيانات؛ يوضح التطبيق أن التغيير ليس دليل اختراق ولا يوجد تاريخ سابق لم يُجمع. |
| اختبارات PC DNA/Timeline | ناجحة | ضمن 34 تحققًا إجمالًا؛ اختبرت الإضافات والإزالات والتغييرات، التخزين وإعادة التحميل، التصدير، الاستعادة الجزئية، وعدم استبدال سجل JSON تالف دون تنبيه. |
| التحقق النهائي من البناء وXAML | ناجح | `dotnet build .\GhostHunterPC.sln --no-restore --verbosity minimal -m:1`؛ التطبيق والاختبارات بنجاح، صفر تحذيرات وصفر أخطاء. |
| أساس ميزة «نفّذها لأجلي» | منفذ | صفحة بخمس مهام ثابتة وخطة قبل المتابعة، وتوضيح النطاق والأثر والتراجع والتوفر، مع تأكيد وإلغاء وسجل محلي للنتائج. |
| قائمة الإجراءات المسموح بها والتأكيد | مختبر | اختبار دخان يتحقق من رفض الإجراءات غير المعروفة والمعدلة وغير المتاحة، ورفض أي إجراء دون تأكيد صريح. لا توجد آلية لتنفيذ أوامر عشوائية. |
| المهام المرتبطة بالخدمات القائمة | منفذة | التنظيم يفتح منظم الملفات، والتكرارات تفتح أداة SHA-256، وعناصر بدء التشغيل تفتح PC DNA، وحالة الجهاز تحدّث معلومات الجهاز. التغييرات تظل ضمن معاينة وتأكيد الأداة الأصلية. |
| العثور على الملفات الكبيرة | غير متاح | لا توجد خدمة تصفية/ترتيب مخصصة حسب الحجم؛ تعرض الواجهة عدم التوفر بدل محاكاة التنفيذ. |
| التراجع والتسجيل في «نفّذها لأجلي» | منفذ | عمليات نقل المنظم تستخدم التراجع الآمن الموجود، والنتائج والإلغاءات تسجل محليًا ضمن PC Timeline دون رفع البيانات أو حفظ مسارات الملفات. |
| نظام التقارير CSV/JSON | منفذ | تقارير معلومات الجهاز مع تصريح أن الفحص الشامل لم يُنفّذ، ومحقق الملفات والتكرارات ومراقبة الجهاز وتعداد تغييرات خطوط الأساس. يختار المستخدم مسار الحفظ؛ تُستبعد مسارات الملفات وأسماء العمليات من التقرير. |
| تصدير PDF | غير متاح | لم تُضف مكتبة PDF أو اعتماد خارجي؛ تعرض الواجهة عدم التوفر بدل إنشاء ملف مزيّف. |
| إعدادات اللغة والمظهر والمراقبة | منفذة ومحفوظة ومختبرة | تُحفظ اللغة والمظهر وفاصل مراقبة الجهاز في `%LOCALAPPDATA%\GhostHunterPC\settings.json` وتُستعاد عند التشغيل. |
| إعدادات الخصوصية والاستثناءات | منفذة ومختبرة | إيقاف حفظ أحداث التطبيق الجديدة، ومجلدات استثناء تطبق على محقق الملفات وفحص التكرارات ومعاينة التنظيم. لا يؤدي تعطيل السجل إلى حذف البيانات الموجودة أو خط الأساس المحلي. |
| الإشعارات | غير متاحة | لا ينشئ التطبيق إشعارات؛ توضح صفحة الإعدادات ذلك. |
| موارد الترجمة العربية والإنجليزية | منفذة | جميع 319 مفتاح ترجمة موجودًا في ملفات JSON منفصلة للغتين، مع التحقق من اكتمال المفاتيح بالتساوي. تُضبط العربية RTL وثقافة ar-SA والإنجليزية LTR وثقافة en-US. |
| اختبارات الإعدادات والتقارير والتعريب | ناجحة | تحققت اختبارات الدخان من حفظ/استعادة الإعدادات والاستثناءات، مطابقة حدود مجلد الاستثناء وتطبيقه على الفحص، تصدير CSV مع الاقتباس وJSON، وتبديل موارد اللغتين والثقافة. |
| التحقق النهائي للجزء 10 | ناجح | `dotnet build .\GhostHunterPC.sln --no-restore --verbosity minimal -m:1`؛ صفر تحذيرات وأخطاء. اختبار الدخان: 372 تحققًا ناجحًا، منها استدعاء مفاتيح الترجمة الـ319 بالعربية والإنجليزية. |
| المراجعة التقنية للجزء 11 | مكتملة | استعادة وبناء الحل ناجحان؛ بناء WPF/XAML بلا تحذيرات أو أخطاء. لم تظهر أخطاء قابلة لإعادة الإنتاج للإصلاح في المراجعة الحالية. |
