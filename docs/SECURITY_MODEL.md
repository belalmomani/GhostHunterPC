# نموذج الأمان

## الأصول التي يجب حمايتها

- ملفات المستخدم وإعداداته.
- سلامة نظام Windows وتكويناته.
- أي بيانات تشخيصية قد تكشف معلومات شخصية.

## قواعد أساسية

- العمل بأقل صلاحيات لازمة، وعدم طلب صلاحية المسؤول دون حاجة موثقة وموافقة المستخدم.
- عدم حذف الملفات أو تعديل النظام بصمت؛ يجب شرح الأثر والحصول على تأكيد قبل الإجراءات المؤثرة.
- التحقق من المدخلات، ومعالجة الأخطاء بصورة صريحة دون نجاح زائف.
- عدم تضمين أسرار أو بيانات اعتماد في الكود أو السجلات.
- لا تنفذ ميزة «نفّذها لأجلي» إلا مهامًا ثابتة محددة في قائمة مسموح بها؛ لا تشغّل أوامر PowerShell/CMD عشوائية أو نصًا مولدًا.
- تعرض الخطة النطاق والأثر قبل التأكيد. الانتقال إلى أداة موجودة لا يتجاوز معاينتها أو تأكيدها الداخلي قبل التغييرات.
- لا تُعطّل الميزة Windows Defender أو جدار الحماية، ولا تحذف ملفات النظام، ولا ترفع بيانات المستخدم.
- لا تُمثّل المهام غير المتاحة على أنها نُفّذت. يجب أن تبقى أي وظيفة جديدة محدودة بالصلاحيات وتُختبر قبل تفعيلها.

## حدود النسخة الحالية

توفّر ميزة «نفّذها لأجلي» خططًا لخمس مهام ثابتة. المهام المدعومة تفتح الأدوات الموجودة، ومهمة حالة الجهاز تستدعي قارئ المعلومات الموجود بعد التأكيد. العثور المخصص على الملفات الكبيرة غير متاح. نقل الملفات أو إرسالها إلى سلة المحذوفات يظل خاضعًا لمعاينة وتأكيد الأداة المعنية؛ لا تنفّذ صفحة «نفّذها لأجلي» هذه التغييرات بنفسها.

تُحفظ نتائج وإلغاءات المهام محليًا في سجل PC Timeline الموجود، من دون مسارات ملفات أو محتواها. لا ترسل الميزة بيانات إلى أي خدمة خارجية.

## التقارير والإعدادات

- تُحفظ التفضيلات في ملف JSON محلي تحت LocalAppData، وتقتصر على اللغة والمظهر وفاصل المراقبة ومجلدات الاستثناء وتفضيل سجل الأحداث.
- يكتب التصدير فقط إلى مسار اختاره المستخدم. CSV يقتبس الحقول ويهرب علامات الاقتباس ويقيّد صيغ الخلايا الخطرة؛ JSON يستخدم التسلسل الآمن من المكتبة القياسية.
- التقارير تجمع تغييرات خطوط الأساس ولا تتضمن مفاتيح العناصر أو قيمها، وتتجنب أسماء الملفات والعمليات. معلومات الجهاز تعرض حقولًا عامة فقط.
- موارد الترجمة ملفات JSON تُوزع محليًا مع التطبيق ولا تُنزّل من الشبكة.
- PDF والإشعارات غير متاحين. لا توجد خدمة ذكاء اصطناعي أو خدمة مدفوعة.
