# معمارية المشروع

## الوضع الحالي

يحتوي الحل حاليًا على تطبيق WPF واحد (`src/GhostHunterPC`). يبدأ التطبيق من `App.xaml` ويفتح `MainWindow.xaml`. النافذة الحالية للعرض فقط؛ ولا تتصل بخدمات النظام أو الشبكة أو التخزين.

## اتجاه التطوير

- إبقاء واجهة المستخدم منفصلة عن أي منطق أعمال يضاف لاحقًا.
- عزل عمليات النظام في مكونات صغيرة ذات واجهات محددة وقابلة للاختبار.
- تمرير الإلغاء والنتائج والأخطاء صراحةً بدل إخفائها.
- تجنب تنفيذ أعمال طويلة على خيط واجهة WPF.
- إضافة مشروع اختبارات عند ظهور منطق مستقل ذي سلوك محدد.

## الاعتماديات

المشروع يعتمد حاليًا على إطار .NET وWPF المضمّنين مع أدوات Windows Desktop SDK، ولا يضيف حزم NuGet خارجية.
